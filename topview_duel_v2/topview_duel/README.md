# TOPVIEW DUEL

## 실행
1. Node.js LTS 설치
2. 이 폴더에서 터미널 또는 CMD 열기
3. `npm install`
4. `npm start`
5. 브라우저에서 http://localhost:3000 접속

## 조작
- WASD: 이동
- 마우스: 조준
- 좌클릭: 평타
- Q / E / R / T: 스킬 1~4

## 포함 기능
- 로비 및 랜덤 1대1 매칭
- 캐릭터 선택 4종
- 캐릭터별 서로 다른 스킬 구성
- 스킬 쿨타임 UI와 마우스 오버 설명
- 플레이어 머리 위 체력바
- 속도를 낮춘 이동과 개선된 전장 배경
- 서버 측 기본 피해/쿨타임/투사체 충돌 처리

개발용 프로토타입이며, 공개 인터넷 서비스로 운영하려면 별도 호스팅과 보안/네트워크 보강이 필요합니다.
